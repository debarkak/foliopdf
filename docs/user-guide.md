# User guide

Open a PDF with **Open**, **Ctrl+O**, or the **+** next to your open tabs. Each tab keeps its own page and zoom. Close a tab with its × or **Ctrl+W**.

| Action | Shortcut |
| --- | --- |
| Find text | Ctrl+F |
| Zoom in or out | Ctrl+Plus or Ctrl+Minus |
| Actual size | Ctrl+0 |
| Switch tabs | Ctrl+Tab or Ctrl+Shift+Tab |
| First or last page | Ctrl+Home or Ctrl+End |
| Rotate the view | R or Shift+R |

Use the toolbar to switch between vertical and horizontal reading or fit the page to the window. Under **Settings → Reading & gestures**, you can turn off pinch zoom or Ctrl+mouse wheel zoom separately. Touchpad input depends on what the system webview delivers to FolioPDF.

Use the text and highlight tools to annotate a PDF. Choose **Save edited copy** to write your changes to a new file. Use the printer icon to open the print dialog.

Under **Settings → About & updates**, choose **Check for updates**. Windows installer and Linux AppImage builds can download and install signed updates. Other builds send you to the downloads page. Save your work before installing an update, which restarts the app.

See the [downloads and platform requirements](../README.md#download).

## Default PDF app

On Windows, install FolioPDF using the setup installer. In **Settings → Apps → Default apps**, search for `.pdf` and select FolioPDF. On Linux, install the Debian package and select FolioPDF under **Open With** in your file manager. An AppImage needs desktop integration to appear in that list.

## Home tabs, history, and document details

Click **+** to open a Home tab. Open a PDF from there or choose a file under **Recent PDFs**. On desktop, FolioPDF stores recent file paths locally. **Settings → History** lets you change how many days are kept. Turning history off clears the list.

Click the information icon in the toolbar to see the file size, page count, and embedded PDF metadata. Enable **Settings → Appearance → Toolbar labels** to show text beside toolbar icons.
