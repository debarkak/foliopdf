Install FolioPDF with APT

The signed repository provides FolioPDF for 64-bit Debian-based distributions, including Ubuntu. It is currently published for amd64.

1. Add the signing key

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://debarkak.github.io/foliopdf/apt/foliopdf-archive-keyring.asc \
  | sudo tee /etc/apt/keyrings/foliopdf-archive-keyring.asc > /dev/null

2. Add the repository

echo 'deb [arch=amd64 signed-by=/etc/apt/keyrings/foliopdf-archive-keyring.asc] https://debarkak.github.io/foliopdf/apt stable main' \
  | sudo tee /etc/apt/sources.list.d/foliopdf.list
sudo apt update

3. Install and update

sudo apt install folio-pdf

# Later, install available FolioPDF updates with:
sudo apt update && sudo apt install --only-upgrade folio-pdf

FolioPDF can check for a newer version under Settings → About & updates. Debian packages use APT to install updates, so the app opens this page with the upgrade command when an update is available.
